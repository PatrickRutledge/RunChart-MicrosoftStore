# Store Assets Folder

This folder contains all assets needed for Microsoft Store submission.

## Screenshots
Place app screenshots in the `screenshots/` folder:
- Use PNG or JPG format
- Recommended resolution: 1920x1080 or 1366x768
- Show key features: chart creation, goal limits, export functionality
- Professional, clean appearance
- Maximum 10 screenshots

## Icons
Place app icons in the `icons/` folder:
- Use PNG format with transparent backgrounds
- Required sizes:
  - 16x16 px (Small icon)
  - 44x44 px (App list icon)
  - 50x50 px (Small tile)
  - 150x150 px (Medium tile)
  - 310x150 px (Wide tile)
  - 310x310 px (Large tile)

## Usage
When submitting to Microsoft Store:
1. Upload screenshots from `screenshots/` folder
2. Upload icons from `icons/` folder
3. Use content from `../STORE_LISTING_CONTENT.md`
4. Upload `../RunChartAnalytics.msix` package

## File Naming Convention
- Screenshots: `screenshot_01.png`, `screenshot_02.png`, etc.
- Icons: `icon_16x16.png`, `icon_44x44.png`, etc.
