# Privacy Policy for Run Chart Visualization

This repository hosts the privacy policy for the Run Chart Visualization app available on the Microsoft Store.

## Privacy Policy URL

Once GitHub Pages is enabled, the privacy policy will be available at:
`https://patrickrutledge.github.io/RunChart-MicrosoftStore/`

## How to Enable GitHub Pages

1. Go to your repository settings on GitHub
2. Scroll down to "Pages" section
3. Under "Source", select "Deploy from a branch"
4. Choose "feature/electron-migration" branch
5. Choose "/ (root)" folder
6. Click "Save"

The privacy policy will then be live at the GitHub Pages URL.

## App Information

- **App Name:** Run Chart Visualization
- **Platform:** Microsoft Store (Windows)
- **Technology:** Electron + Vue.js
- **Privacy:** Zero data collection, completely offline

## Microsoft Store Submission

This privacy policy supports the Microsoft Store submission requirements for app certification.
